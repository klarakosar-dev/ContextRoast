# ContextRoast v0.2.2 alpha

Launch maintenance release. The evaluation algorithm and provider behaviour are unchanged.

- Shorter documentation with runnable examples and no obsolete preparation reports.
- Manual draft releases, dependency and secret checks, and pinned CI actions.
- Package repository links and a private security-reporting route.

The bundled FAQ example intentionally fails holdout validation: 2/2 correct with full context, 1/2 after removal. Its 29.14% reduction is a serialized input-size proxy, not measured model-token or cost savings.

Python entrypoints execute unsandboxed code, and detailed reports may contain sensitive data. This is an experimental alpha with curated examples, not a production benchmark.
