# ContextRoast v0.2.1 — first alpha release

A Python CLI for finding removable LLM context fields, detecting regressions and estimating whether the savings justify evaluation costs.

## Highlights

- **Bring Your Own Agent:** evaluate a trusted synchronous Python callable using labelled JSON/YAML test cases.
- **Greedy context elimination:** remove candidate fields only when the optimisation-set score stays within the configured tolerance.
- **Integrated holdout gate:** compare full versus reduced context on separate, untouched cases. A failed gate writes reports, marks exports not deployment-ready, and exits 1.
- **Context Roast:** generate a 1280×640, aggregate-only SVG with field reduction, accuracy, token/proxy reductions, and visible validation status.
- **Rebranded package:** `pip install .` from a checkout installs the `contextroast` command and `contextroast` Python package.
- Offline mock demonstrations, optional OpenAI-compatible API adapter, machine-readable reports and field-selection exports.

## Reproducible example

The included FAQ retriever removes 2 of 5 collections, retaining 8/8 correct answers on the optimisation set. On a separate two-case holdout, full context scores 2/2 and reduced context scores 1/2: **FAIL**. This is intentionally surfaced in the report and share card. Its 29.14% reduction is a **serialized input-size proxy**, not verified LLM-token or cost reduction.

All example labels and documents are curated. No real LLM or production agent benchmark was performed. Passing a small holdout cannot establish generalisation or production safety.

## Safety and limitations

The Python provider executes **unsandboxed** imports and functions after explicit `--allow-paid` consent; internal API calls and spending are not bounded. The remote API provider also requires opt-in. Detailed JSON/Markdown reports may contain sensitive case inputs and predictions. The SVG card includes aggregates only.

Greedy elimination is not globally optimal, exact-match scoring requires known structured targets, and token/cost estimates depend on incomplete model-usage assumptions.

See the [README](../../README.md), [holdout guide](../holdout.md) and [security notice](../../SECURITY.md). The GitHub release includes verified wheel and source distributions. This alpha has no PyPI upload and makes no claim of verified savings on real model traffic.
